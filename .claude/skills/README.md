# Third-party design skills (provenance and licenses)

These skills were adopted from open-source projects to raise the frontend design quality
bar, after manual review of their full contents. They are instruction files only — no
scripts, hooks, or executable content from the source repos was installed.

| Skill | Source | License | Changes |
|---|---|---|---|
| `minimalist-ui` | [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) `skills/minimalist-skill` | MIT | copied verbatim |
| `redesign-existing-projects` | [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) `skills/redesign-skill` | MIT | copied verbatim |
| `impeccable-craft` | [pbakaus/impeccable](https://github.com/pbakaus/impeccable) `skill/reference/{craft-floor,operate,polish}.md` | Apache 2.0 | three reference playbooks copied verbatim; local SKILL.md wrapper added noting that Impeccable's script/hook workflow is not installed |

Role in this project: `impeccable-craft` sets the always-on quality floor for UI work;
`minimalist-ui` supplies the editorial visual language (fits the book/paper theme);
`redesign-existing-projects` drives the post-build design audit/polish pass.
