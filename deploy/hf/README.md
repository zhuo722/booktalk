# BookTalk — live demo

Pick one of the five public-domain example books (or upload your own PDF, up to
20 MB), hold the mic button, ask a question, and hear the book answer — grounded
in its own pages, with the passages it used shown on screen.

Source, architecture and the retrieval eval: https://github.com/zhuo722/booktalk

This is a public demo with per-visitor rate limits; uploads are visible to
other visitors and are wiped whenever the Space restarts.
