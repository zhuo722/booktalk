# BookTalk 设计说明 — 书架页（着陆页 / 选书页）
[English](DESIGN-SHELF.md) · **中文**

在现有对话页前面加一个新的**首屏**：用户先落到自己的书架上，选一本书，然后才进入对话。
它的骨架照搬 press.stripe.com；配色用 DESIGN.md v3 里那套浅色的 "Studio Light"。对话页的
行为一点都不改。

## 参考骨架（在 press.stripe.com 上按 1366px 视口测得）

这里要复现的是结构，不是逐像素对齐：

| 元素 | 它在那个页面上是什么 |
|---|---|
| `main > container` | 单列，通栏铺满 |
| `header` | 只占左上角：`h1` 字标（serif，约 17.6px）在 `h2` 副标题（serif 斜体，约 16px）上方；左右内边距约 66px；然后是**约 229px 的空白**，才出现第一本书 |
| `.PressHomepageProductList` | 纵向堆叠，一行一本书，行高约 166px，行与行之间没有间隔——这些书看起来像一摞略带角度俯视的实物 |
| `button.PressHomepageBook` | 整行都是点击区域：`display:flex; align-items:center; padding: 0 96px`；行背景是这本书自己的布面颜色；里面 `.PressHomepageBook__text` 装 `h2` 书名和 `h3` 作者 |
| `canvas.PressHomepageCanvas` | 一层 WebGL，在这些行之上画出三维的书（我们改用 CSS 3D——见下文） |
| `.PressHomepageMenu__bookList` | 最左侧一条固定导轨，宽约 34px：每本书一个小刻度 `button`，同时充当索引和滚动位置 |
| 左下角 | 一个小小的 `?` 入口 |

核心节奏是：**大片安静，然后一次一本书地缓慢纵向排开，每一本都是一件实物而不是一张卡片。**
照搬这一点。照搬左侧刻度导轨。照搬极轻的页头。不要照搬深色底。

## 配色（浅色——取自 DESIGN.md v3，未改动）

底色 `--canvas #E9EBF2`，所有内容背后是那两团固定的浅色环境光晕；`--ink #171A20`、
`--ink-soft #5F6672`、`--blue #3D63F2`、`--blue-soft #DCE7FF`、`--line #E2E5EB`，玻璃相关
token 沿用已定义的值。书的“布面”颜色取封面色块已经在用的那几组浅色（暖色
`#FFD9C7→#F6B9D2`，冷色 `#BFD8FF→#A3E7DB`），再加两个浅中性色（sand `#F0E6D2`、
mist `#DDE4EC`），这样六本书的书架不会出现重复颜色：色相由书名哈希确定性地选出，和封面
色块现在的做法完全一样。

## 书本对象（CSS 3D，不用 WebGL）

每本书都是一个平放的立体块，视线略微从上往下——就是 Stripe Press 的那个姿态：

- 行：通栏铺满，`min-height: 168px`，内容居中，行与行之间没有间隔。
- 立体书块：一个 `~560px × 108px` 的块，行上加 `perspective: 1400px`，块上加
  `transform: rotateX(46deg)`，于是能看到**顶面**（封面）和一条细的**前切口**（书页）。
  用两个叠起来的元素加一层阴影搭出来：
  - 顶面：这本书的浅色渐变，加沿着上缘的 1px 内高光；
  - 前切口：高 10–12px，同色相更浅一档，加 3 条发丝级的“书页”线，让它看上去是纸而不是
    塑料；
  - 落地阴影：`0 18px 30px rgba(23,26,32,.14)`，hover 时收紧。
- 文字放在顶面上，排法和真书的书脊一样：**作者靠左（等宽字体，大写，字距 0.09em，
  `--ink-soft`），书名居中（Literata，`--ink`），右边一个小圆形 BookTalk 标记**。过长的
  书名截成一行，末尾省略号。
- 任何一种布面上的文字都必须达到 4.5:1 以上；如果某个哈希出来的渐变达不到，就把渐变调浅，
  而不是把文字调深（两个渐变端点都要测）。

## 交互

- **Hover / 聚焦**：立体书块抬起（`translateY(-6px)`，阴影变大，180ms），左侧导轨里对应的
  那条刻度变成 `--blue`。其他什么都不动——不倾斜，不做缩放弹跳。
- **点击 / Enter**：这本书成为当前书，应用切到对话页。已就绪的书直接进去；仍在入库的书
  也进去（对话页本来就会渲染它自己的入库面板）；失败的书进入对话页的失败状态。
- **左侧刻度导轨**：固定定位，垂直居中，宽约 34px，每本书一条 14×2px 的刻度，颜色
  `--line-strong`；指针位置或滚动位置对应的那条是 `--blue`，宽 20px。点击某条刻度把它对应
  的书滚动到视野内（`scrollIntoView({behavior:'smooth'})`，在 `prefers-reduced-motion` 下
  不执行）。每条刻度都是真正的 `button`，`aria-label` 写明它是哪本书；只有书的数量为 1 时
  整条导轨才设 `aria-hidden`。
- **滚动**：就是普通的文档滚动。没有视差，不劫持滚动，没有出场动画——operate.md 仍然禁止
  加载时的编排动画。

## 页面构件

- **页头**（左上角，没有横条，没有玻璃）：`BookTalk` 字标用 Literata，下面是斜体副标题
  `Ask your books out loud`。左右内边距 64px，顶部 24px。
- **空书架**（还没有书）：沿用现有的 Hero/上传内容，在同样的安静里居中——标题、一行说明、
  拖放区域。书架和上传入口是同一个页面；有书之后，上传位变成**堆叠的最后一行**：同样姿态
  的一个浅色虚线立体块，上面写 "Add a book · drop a PDF or click"，hover 抬起效果相同。
- **正在入库的书**立刻出现在堆叠里：布面 60% 不透明度，前切口上有一条 `--blue` 的进度
  下划线，作者的位置换成等宽字体的阶段标签（"SITUATING 47%"）。轮询和阶段文案已经能用
  了——直接复用 `useLibrary`。
- **删除**：hover 时在行的右侧边距上、立体书块之外露出一个小的无填充图标按钮，确认行为
  沿用现有的。
- **左下角的 `?`**：一个玻璃质感的小圆按钮，点开一个朴素的浮层：这个应用做什么，以及一句
  说明——回答只来自选中的那本书。

## 两个页面之间的路由

不引入路由库。`App.tsx` 里保存 `view: "shelf" | "chat"`：
- 初始 view 是 `"shelf"`；
- 选中一本书会设置当前书，并令 `view = "chat"`；
- 对话页的页头增加一个**返回入口**——BookTalk 字标变成一个按钮（"← All books"），点它回到
  `"shelf"`——返回时必须调用现有的 `stopAll()`，否则正在朗读的回答会继续播；
- 换选另一本书本来就会停止播放（App 里现有的 effect）；保留它。
- 对话页的左侧导轨完全按现在的样子继续工作——书架是新增的一个入口，不是它的替代。

## 验收标准（强制）

craft-floor 的 Verify 清单；对完成后的成果跑一遍 redesign-existing-projects 审查；测量每一
种生成出来的布面颜色上文字的对比度（两个渐变端点都测），以及玻璃背景上文字在无模糊降级下
的对比度；`npm run build` 零 TS 错误；`npx vitest run` 全绿；键盘路径完整（Tab 能到达每一
本书和每一条刻度，Enter 打开，焦点环出现在立体书块本身上）；1366 / 1024 / 900 / 375px 四
个宽度都要看——窄屏下导轨隐藏，立体书块宽度收窄到视口宽度减 32px，rotateX 向 30deg 变平，
让文字保持清晰。
